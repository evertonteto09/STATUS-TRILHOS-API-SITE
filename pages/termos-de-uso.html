Termos de Uso

Regras para solicitação e utilização da API Status Metropolitano.

Última atualização: 20 de setembro de 2026 Serviço gratuito
Termos de Uso Política de Privacidade
✓
Em poucas palavras

A API é gratuita, destinada a usos não comerciais e deve ser utilizada de forma responsável, respeitando os limites de acesso e a finalidade do serviço.

01

Sobre o serviço

A API Status Metropolitano disponibiliza informações públicas relacionadas ao status e à operação de linhas metropolitanas e ferroviárias.

O serviço foi desenvolvido para apoiar projetos pessoais, acadêmicos, educacionais e informativos, por meio de uma interface de acesso programático aos dados disponibilizados pela API.

02

Aceitação dos termos

Ao solicitar ou utilizar uma API-Key, o usuário declara que leu e compreendeu estes Termos de Uso e concorda em respeitá-los durante a utilização do serviço.

03

Gratuidade e disponibilidade

A API Status Metropolitano é gratuita e não possui planos pagos ou barreiras de paywall.

A gratuidade não constitui garantia de disponibilidade contínua. O serviço pode passar por manutenção, atualização, alterações técnicas, interrupções temporárias ou encerramento de funcionalidades.

04

Finalidades permitidas

O usuário pode utilizar a API em projetos pessoais, acadêmicos, educacionais e informativos, incluindo estudos, experimentos de programação, bots e ferramentas sem finalidade comercial.

Usuários menores de idade também podem utilizar o serviço, desde que respeitem estes termos, não abusem da infraestrutura e sigam as boas práticas de utilização.

05

Uso comercial

É expressamente proibida a utilização da API para fins comerciais.

Isso inclui, entre outros casos, vender acesso aos dados, monetizar diretamente o conteúdo fornecido pela API, revender informações, criar serviços pagos baseados no serviço ou utilizar a API como componente de um produto comercial.

O projeto incentiva especialmente o uso em iniciativas pessoais, acadêmicas, educacionais e informativas.

06

Uso responsável e prevenção de abusos

A API utiliza limites de requisições para preservar a estabilidade do serviço e permitir utilização equilibrada entre os usuários.

Não é permitido enviar requisições de forma abusiva, tentar sobrecarregar a infraestrutura, contornar limites, explorar vulnerabilidades, realizar testes destrutivos ou utilizar mecanismos para prejudicar a disponibilidade do serviço.

Medidas de proteção, como bloqueios temporários ou permanentes, podem ser aplicadas quando houver indícios de abuso.

07

API-Key

A API-Key deve ser tratada como uma credencial individual. O usuário é responsável por protegê-la e por evitar sua publicação em repositórios, páginas públicas, imagens, mensagens ou outros locais acessíveis por terceiros.

Em caso de exposição ou comprometimento da chave, o usuário deve solicitar a revogação e realizar um novo procedimento de emissão.

08

Dados e fontes de informação

As informações disponibilizadas pela API são obtidas a partir de dados públicos e fontes de monitoramento do transporte metropolitano.

Podem ocorrer atrasos, indisponibilidades, divergências temporárias ou informações desatualizadas em razão de problemas na fonte original ou na cadeia de processamento.

Importante

Para decisões de viagem ou informações críticas de operação, consulte sempre as redes e os canais oficiais de monitoramento dos trilhos.

09

Responsabilidade pela utilização

O usuário é responsável pela forma como utiliza os dados retornados pela API e pelas aplicações que desenvolver a partir deles.

O Status Metropolitano não garante que os dados estarão disponíveis ou livres de falhas em todos os momentos e não se responsabiliza por decisões tomadas exclusivamente com base nas informações disponibilizadas pela API.

10

Revogação e suspensão

O Status Metropolitano poderá suspender ou revogar uma API-Key quando identificar uso comercial, abuso da infraestrutura, tentativa de contornar mecanismos de proteção ou outras violações destes termos.

O usuário também pode solicitar a revogação da própria API-Key por meio do contato oficial do projeto.

11

Alterações dos termos

Estes Termos de Uso podem ser atualizados para refletir mudanças no funcionamento da API, nas medidas de segurança ou nas funcionalidades do serviço.

A versão vigente permanecerá disponível nesta página.
